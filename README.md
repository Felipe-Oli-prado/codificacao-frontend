# 🚀 Frontend Vault & Code Snippets

Um repositório dedicado ao armazenamento, organização e consulta de componentes reutilizáveis, snippets de código, animações e experimentos de desenvolvimento frontend.

---

## 📌 Sobre o Repositório

Este espaço serve como uma biblioteca centralizada para guardar soluções práticas do dia a dia no ecossistema frontend, incluindo:
- 🧩 **Componentes UI:** Botões, modais, carrosséis, formulários.
- ⚡ **Snippets & Helpers:** Funções utilitárias JavaScript/TypeScript, custom hooks, expressões regulares.
- 🎨 **Estilos & Animações:** Efeitos CSS, transições e microinterações.
- 💻 **Mini-projetos:** Landing pages e provas de conceito (PoCs).

---

## 🛠️ Tecnologias Utilizadas

- **Linguagens:** HTML5, CSS3, JavaScript (ES6+), TypeScript
- **Frameworks & Bibliotecas:** React, Next.js, Vue.js *(ajuste conforme o seu stack)*
- **Estilização:** Tailwind CSS, Styled Components, Sass/SCSS
- **Build Tools:** Vite, Webpack
